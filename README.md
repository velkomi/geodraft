# GeoDraft

GeoDraft — программа для Windows. В ней:

- векторный чертёж;
- сведения НСПД и Росреестра;
- ПЗЗ и градостроительные регламенты;
- генпланы и красные линии;
- поиск свободной земли, права и аренда;
- экспорт в DXF/DWG.

## Скачать

Последняя версия: **[страница релизов → Latest](https://github.com/velkomi/geodraft/releases/latest)**. Скачайте файл `GeoDraft-<версия>-Setup.exe` и запустите.

- Права администратора не нужны.
- Установщик предлагает диск C: или D: и рекомендует тот, где больше свободного места.
- Он создаёт ярлык на рабочем столе.
- Папку, где будут храниться все проекты и документы, вы выбираете в установщике. Потом её можно поменять в программе: Файл → «Выбрать папку для всех проектов…».

Файлы `models-*` скачивать вручную не нужно. Модели распознавания легенд ПЗЗ (около 1,5 ГБ) ставятся из программы: Справка → «Проверить обновления…».

## Обновления

Установленный GeoDraft обновляется сам: Справка → «Проверить обновления…». Окно показывает установленную и последнюю версии и что в ней нового. Кнопка «Обновить» скачивает и ставит обновление, после чего программа перезапускается.

Программа и модели распознавания обновляются отдельно: если в новом выпуске изменились только модели, скачиваются только они. Каждый файл перед установкой проверяется по контрольной сумме SHA-256.

## История версий

Все изменения можно посмотреть в программе: Справка → «История версий…». Они же есть в описаниях [релизов](https://github.com/velkomi/geodraft/releases).

## Удаление

Пуск → GeoDraft → «Удалить GeoDraft» или «Приложения Windows». Проекты и рабочие данные при удалении не удаляются.
